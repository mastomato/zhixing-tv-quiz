# 知行答题 TV

**版本 1.0.0** · Android TV 离线答题应用 · 适用于 Android 5.0+

Android TV 独立答题软件，内置 PoHW-CN-K12 项目中的 5,735 道四选一题及解析。用遥控器方向键移动焦点，按确定键直接作答。当前焦点显示紫色描边；答对后自动进入下一题，答错后显示正确选项和解析。所选设置、答题统计与错题 ID 保存在应用本机数据。

主界面可按年级、学期（不限 / 上 / 下）、学科、题量和教材版本筛选。教材版本支持“通用题库 / 人教版 / 统编版”：通用题库使用全部 5,735 道题；人教版只使用 `giszh86/cn-math-taxonomy` 来源的数学、英语和物理题；统编版只使用该来源的语文题。当前题库不含可核对的其他出版社版本，切换版本时不会把通用生成题误标为指定教材版本。

学科列表另有“奥数”入口，直接抽取原项目 `generated-olympiad` 来源的 498 道题，覆盖小学 1–6 年级。这些题也保留在“数学 + 通用题库”和“全部学科 + 通用题库”练习中。

背景音乐默认开启并在离开应用时暂停；答对、答错和整组完成时有不同音效。音乐和音效可以分别在主界面关闭。所有音频由 `tools/make_audio.py` 合成，随 APK 离线提供。

## 构建

需 JDK 17、Android SDK API 33 与 Build Tools 34。设置 `JAVA_HOME`、`ANDROID_HOME`，然后运行：

```sh
bash build-local.sh
```

脚本会输出 `知行答题-TV.apk`，首次运行会在 `build/` 生成本地签名密钥。该目录已被 `.gitignore` 排除；以后更新同一包名时需保留同一密钥。也可通过 `SIGNING_KEYSTORE`、`SIGNING_PASSWORD`、`SIGNING_ALIAS` 指定自己的签名配置。

## 安装

通过 ADB 安装：

```sh
adb install -r 知行答题-TV.apk
```
